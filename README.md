# Корейский SRS 🇰🇷

Приложение для запоминания корейских слов с системой интервальных повторений (SRS).

**Приложение:** https://kupavochka-crypto.github.io/korean-srs/

## Что внутри

- **Карточки** — ежедневные повторения по алгоритму SRS (SM-2)
- **Аудирование** — угадай перевод по звучанию
- **Квиз** — русское слово → выбери корейский вариант из 4
- **Словарь** — добавление, сканирование с фото (OCR через Gemini), массовая разметка тегами
- **Прогресс** — статистика: сколько слов выучено, сколько дней уходит на запоминание
- **Темы** — BTS 💜 или Stray Kids 🖤 (картинки, приветствия, GIF-награды)

## Как установить (для телефона)

### iPhone (Safari)
1. Откройте адрес приложения в **Safari**.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Выберите **«На экран "Домой"»** → **«Добавить»**.
4. Иконка приложения появится на рабочем столе.

### Android (Chrome)
1. Откройте адрес приложения в **Chrome**.
2. Нажмите **⋮ (три точки)** вверху.
3. Выберите **«Установить приложение»**.
4. Подтвердите — иконка появится на рабочем столе.

Приложение работает без интернета после первой загрузки (данные хранятся на устройстве).

## Как настроить распознавание с фото (ИИ)

1. Зайдите в **Настройки** → раздел «Распознавание текста».
2. Получите бесплатный ключ на странице [AI Studio](https://aistudio.google.com/apikey) (кнопка «Get API key»).
3. Вставьте ключ в поле **«Gemini API ключ»**.
4. Нажмите **«📷 Сканировать»** и сфотографируйте страницу учебника.

> **Если сканирование не работает** — в настройках в разделе «Прокси для Gemini» должен
> стоять адрес прокси: `https://vercel-proxy-zeta-fawn.vercel.app/api/gemini`.
> Он нужен для стабильного подключения к Gemini API.
> Очистите поле, чтобы подключаться напрямую.

## Для разработки

```bash
npm install        # установить зависимости
npm run dev        # локальная разработка
npm run build      # собрать PWA
npm run deploy     # опубликовать на GitHub Pages (ветка gh-pages)
```

Прокси для Gemini (Vercel): `vercel-proxy/api/gemini.js`. Деплой:
`cd vercel-proxy && npx vercel --prod`

## Данные

Слова, категории, история повторений и прогресс хранятся локально на устройстве
(IndexedDB) и не требуют аккаунта.
